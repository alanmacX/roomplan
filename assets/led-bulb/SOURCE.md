# Lightbulb LED

[Poly Haven Lightbulb LED](https://polyhaven.com/a/lightbulb_led), [CC0 1.0](https://polyhaven.com/license). `bulb.js` contains the mesh from the 1K glTF export and 512-pixel copies of its base-color, normal, and packed roughness/metallic maps. It was packaged with `tools/pack-bulb.py` so the demo can also be opened as a local HTML file without making network requests.
